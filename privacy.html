translate-kemo

개인정보 처리방침

시행일: 2026년 10월 28일

translate-kemo는 개발자가 운영하는 서버가 없습니다. 이용자 정보를 개발자에게 보내지 않고, 광고·분석·추적 도구도 쓰지 않습니다. 번역할 글과 소리는 이용자가 직접 넣은 API 키로 Google Gemini와 Soniox에 바로 전송됩니다.

1. 개발자가 수집하는 정보

없습니다. 회원 가입, 로그인, 사용 통계, 오류 보고, 광고 식별자 수집 기능이 없습니다.

2. 기기 안에만 저장되는 정보

아래 정보는 이용자의 iPhone 안(앱과 앱 확장이 함께 쓰는 저장 공간)에만 저장되며, 앱을 지우면 함께 삭제됩니다.

  • Gemini·Soniox API 키와 앱 설정
  • 번역 기록, 용어집, 금지어, 표현 노트와 공부 기록
  • 이용자가 고른 프로필 이미지, 캐릭터 이름 등 꾸미기 설정

설정의 백업 기능을 쓰면 위 정보가 JSON 파일로 만들어지며, 이 파일에는 API 키도 들어 있습니다. 파일을 어디에 저장하거나 누구와 공유할지는 이용자가 정하며, 개발자에게는 전달되지 않습니다.

3. 외부 서비스로 전송되는 정보

기능을 쓰는 순간에만, 이용자의 기기에서 해당 서비스로 직접 전송됩니다. 개발자 서버를 거치지 않습니다.

받는 곳보내는 정보쓰는 기능
Google Gemini API번역할 글, 사진(이미지), 음성으로 읽을 글번역, 독음, 사전, 음성 읽기, 사진 번역
Soniox마이크 소리, 화면 기록 확장으로 받은 다른 앱의 소리대화 모드, 말로 입력, 화면 소리 번역
unavatar.io이용자가 입력한 X(트위터) 계정 이름X 프로필 사진을 아바타로 표시 (입력한 경우에만)
Apple말로 입력할 때의 음성기기에서 처리할 수 없는 언어일 때만 Apple 음성 인식 서버 사용

Google과 Soniox로 보낸 정보는 이용자가 키를 발급받은 계정의 약관과 각 회사의 개인정보 처리방침에 따라 처리됩니다. 특히 Gemini API를 무료 등급으로 쓰면 Google이 보낸 내용을 서비스 개선에 쓸 수 있으니 Google의 약관을 확인하세요.

  • Gemini API 추가 서비스 약관 · Google 개인정보처리방침
  • Soniox (사이트 하단의 Privacy Policy)
  • unavatar.io

일본어 독음, 사진 속 글자 위치 찾기, iOS 26의 기기 안 AI 사전은 기기 안에서만 처리되어 외부로 나가지 않습니다.

4. 앱이 요청하는 권한

  • 마이크: 대화 모드와 말로 입력에서 목소리를 받아 적습니다.
  • 음성 인식: 말로 입력을 기기 안에서 받아 적습니다.
  • 카메라·사진: 사진 속 글을 번역하고, 번역한 이미지를 사진 앱에 저장합니다.
  • 화면 기록: 화면 소리 번역을 켰을 때만 다른 앱의 소리를 받습니다. 화면 영상은 쓰지 않습니다.

권한은 iPhone 설정 앱에서 언제든 끌 수 있으며, 끄면 해당 기능만 쓸 수 없습니다.

5. 보관과 삭제

개발자는 정보를 보관하지 않습니다. 기기 안의 정보는 앱 안에서 기록을 지우거나 앱을 삭제하면 사라집니다. 외부 서비스에 보낸 정보의 보관과 삭제는 각 서비스의 정책을 따릅니다.

6. 아동

이 앱은 아동을 대상으로 하지 않으며, 아동의 정보를 따로 수집하지 않습니다.

7. 바뀔 때

이 방침이 바뀌면 이 페이지에 새 시행일과 함께 올립니다.

Summary in English

translate-kemo has no developer-run server and collects no data. There is no account, analytics, advertising or tracking. Settings, API keys, history and notes are stored only on the device. When you use a feature, the text, images or audio you choose are sent directly from your device to Google Gemini or Soniox using API keys you provide, and are handled under those services' terms. If you enter an X username for your avatar, it is sent to unavatar.io to fetch the profile picture. Contact: GitHub Issues at github.com/kkkougaa/translate-kemo.
